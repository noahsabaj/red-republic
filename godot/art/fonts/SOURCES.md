# Where the type came from

Written by `tools/fetch_fonts.py`. Everything below is ParaType's
PT family under the **SIL Open Font Licence 1.1** (`OFL.txt` beside
this file), drawn for the *Public Types of the Russian Federation*
programme -- state type for state documents, which is what this
interface is dressed as.

| file | upstream | what it sets |
|---|---|---|
| `PTSans-Regular.ttf` | [PT_Sans-Web-Regular.ttf](https://github.com/google/fonts/blob/main/ofl/ptsans/PT_Sans-Web-Regular.ttf) | Running prose, and anything a player reads a sentence of. |
| `PTSans-Bold.ttf` | [PT_Sans-Web-Bold.ttf](https://github.com/google/fonts/blob/main/ofl/ptsans/PT_Sans-Web-Bold.ttf) | Emphasis inside prose, and the name of a thing in a row. |
| `PTSans-Italic.ttf` | [PT_Sans-Web-Italic.ttf](https://github.com/google/fonts/blob/main/ofl/ptsans/PT_Sans-Web-Italic.ttf) | The briefing, which is somebody speaking rather than the state stating. |
| `PTSansNarrow-Regular.ttf` | [PT_Sans-Narrow-Web-Regular.ttf](https://github.com/google/fonts/blob/main/ofl/ptsansnarrow/PT_Sans-Narrow-Web-Regular.ttf) | Labels, column heads and buttons: capitals, letterspaced, in a hurry. |
| `PTSansNarrow-Bold.ttf` | [PT_Sans-Narrow-Web-Bold.ttf](https://github.com/google/fonts/blob/main/ofl/ptsansnarrow/PT_Sans-Narrow-Web-Bold.ttf) | Title blocks and section heads -- the stamped part of a form. |
| `PTMono-Regular.ttf` | [PTM55FT.ttf](https://github.com/google/fonts/blob/main/ofl/ptmono/PTM55FT.ttf) | Every figure. Tabular, so a column of numbers stops shuffling. |
